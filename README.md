# Titanic Data Cleaning

This project cleans an unclean Titanic dataset using **Python** and **Pandas** in **Google Colab**.

## Key Steps

* **Loaded the dataset:** Imported raw data for processing.
* **Handled missing values:** Fixed null entries in columns like Age and Cabin.
* **Removed duplicate rows:** Cleared out redundant data.
* **Converted data types:** Standardized formats for analysis.
* **Created new columns:** Engineered new features from existing data.
* **Saved the cleaned dataset:** Exported the final result to a CSV file.

## Tech Stack

* **Python**
* **Pandas**
* **Google Colab**
